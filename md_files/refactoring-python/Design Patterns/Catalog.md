# The Catalog of Design Patterns

 These patterns explain how to assemble objects and classes into larger structures while keeping these structures flexible and efficient. [Adapter](Adapter.md) [Bridge](Bridge.md) [Composite](Composite.md) [Decorator](Decorator.md) [Facade](Facade.md) [Flyweight](Flyweight.md) [Proxy](Proxy.md)
