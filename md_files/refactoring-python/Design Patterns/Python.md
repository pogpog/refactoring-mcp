#### Decorator
 Lets you attach new behaviors to objects by placing these objects inside special wrapper objects that contain the behaviors. [Main article](Decorator.md) [Usage in Python](Decorator/Python/Example.md) [Code example](Decorator/Python/Example.md) ![Facade](#) 
#### Facade

#### Flyweight
 Lets you fit more objects into the available amount of RAM by sharing common parts of state between multiple objects instead of keeping all of the data in each object. #### Proxy
 Lets you provide a substitute or placeholder for another object. A proxy controls access to the original object, allowing you to perform something either before or after the request gets through to the original object. #### Behavioral Patterns
 ![Chain of Responsibility](#) 
#### Chain of Responsibility
 Lets you pass requests along a chain of handlers. Upon receiving a request, each handler decides either to process the request or to pass it to the next handler in the chain. [Main article](Chain%20Of%20Responsibility.md) [Usage in Python](Chain%20Of%20Responsibility/Python/Example.md) [Code example](Chain%20Of%20Responsibility/Python/Example.md) ![Command](#) 
#### Command
 Turns a request into a stand-alone object that contains all information about the request. This transformation lets you pass requests as a method arguments, delay or queue a request's execution, and support undoable operations. [Main article](Command.md) [Usage in Python](Command/Python/Example.md) [Code example](Command/Python/Example.md) ![Iterator](#) 
#### Iterator
 Lets you traverse elements of a collection without exposing its underlying representation (list, stack, tree, etc.). [Main article](Iterator.md) [Usage in Python](Iterator/Python/Example.md) [Code example](Iterator/Python/Example.md) ![Mediator](#) 
#### Mediator
 Lets you reduce chaotic dependencies between objects. The pattern restricts direct communications between the objects and forces them to collaborate only via a mediator object. [Main article](Mediator.md) [Usage in Python](Mediator/Python/Example.md) [Code example](Mediator/Python/Example.md) ![Memento](#) 
#### Memento
 Lets you save and restore the previous state of an object without revealing the details of its implementation. [Main article](Memento.md) [Usage in Python](Memento/Python/Example.md) [Code example](Memento/Python/Example.md) ![Observer](#) 
#### Observer
 Lets you define a subscription mechanism to notify multiple objects about any events that happen to the object they're observing. [Main article](Observer.md) [Usage in Python](Observer/Python/Example.md) [Code example](Observer/Python/Example.md) ![State](#) 
#### State
 Lets an object alter its behavior when its internal state changes. It appears as if the object changed its class. [Main article](State.md) [Usage in Python](State/Python/Example.md) [Code example](State/Python/Example.md) ![Strategy](#) 
#### Strategy
 Lets you define a family of algorithms, put each of them into a separate class, and make their objects interchangeable. [Main article](Strategy.md) [Usage in Python](Strategy/Python/Example.md) [Code example](Strategy/Python/Example.md) ![Template Method](#)
